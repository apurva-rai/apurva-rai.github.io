# apurva-rai.github.io

Personal site of Apurva Rai. One static page, no build step.

- `index.html` holds the page, its styles and its script.
- `fonts/` holds Source Serif 4 (SIL Open Font License, see `fonts/LICENSE.md`). The page loads nothing from other sites.
- `Apurva_Rai_CV.pdf` is the CV the page links to. Replace the file to update it and keep the name.
- `apurva-rai.jpg` is the portrait.

To update the text, edit `index.html` and change the date in the footer.
